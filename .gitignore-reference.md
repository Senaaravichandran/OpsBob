# .gitignore Quick Reference

## ✅ What's Ignored (Won't be committed)

### Secrets & Environment
- `.env` - Your actual environment variables with secrets
- `.kiro/` - AI assistant settings

### Build Artifacts
- `node_modules/` - NPM dependencies (all projects)
- `__pycache__/` - Python bytecode cache
- `frontend/dist/` - Frontend build output
- `mcp-server/dist/` - MCP server build output
- `*.pyc` - Compiled Python files

### Runtime Data
- `incident-history.json` - Runtime incident data
- `memory/context.txt` - AI context memory
- `demo-service/debug/traces.js` - Debug traces
- `*.log` - All log files

### IDE & OS
- `.vscode/` - VS Code settings
- `.idea/` - IntelliJ settings
- `.DS_Store` - macOS metadata
- `Thumbs.db` - Windows thumbnails

## ✅ What's Tracked (Will be committed)

### Source Code
- `backend/*.py` - Python backend code
- `demo-service/*.js` - Demo service code
- `frontend/src/**/*` - Frontend source files
- `mcp-server/src/**/*` - MCP server source

### Configuration
- `.env.example` - Environment template (no secrets!)
- `package.json` - Node.js dependencies
- `requirements.txt` - Python dependencies
- `tsconfig.json` - TypeScript config
- `vite.config.js` - Vite config
- `orchestrate/*.yaml` - Agent configs

### Documentation
- `README.md` - Main documentation
- `ARCHITECTURE.md` - Architecture docs
- `docs/**/*` - All documentation files

### Scripts
- `*.sh` - Shell scripts

## 🔍 Quick Commands

### Check what's ignored
```bash
git status --ignored
```

### Check if a file is ignored
```bash
git check-ignore -v <filename>
```

### See all tracked files
```bash
git ls-files
```

### Force add an ignored file (use carefully!)
```bash
git add -f <filename>
```

## ⚠️ Important Notes

1. **Never commit `.env`** - It contains secrets!
2. **Always commit `.env.example`** - It's a template
3. **Dependencies are ignored** - They'll be installed via `npm install` or `pip install`
4. **Build outputs are ignored** - They'll be generated during deployment

## 🆘 Accidentally Committed a Secret?

```bash
# Remove from tracking but keep locally
git rm --cached .env
git commit -m "Remove .env from tracking"
git push

# Then rotate your secrets immediately!
```
